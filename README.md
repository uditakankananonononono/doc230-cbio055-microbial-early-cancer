# doc230-cbio055-microbial-early-cancer
Preregistered audit of tumor-vs-normal separation from TCGA microbial abundances (Poore 2020 data) for early-stage cancers. See PREREG.md, RESULTS.md, src/run.py (needs /tmp/poore/X.npy built from voom.csv; hashes in data_manifest). Gates D2 and D4 met originally; AUDIT: D2 downgraded to "met against a weak baseline, not robust" (extended-baseline margin 0.004, leave-center-out AUROC 0.668), see RESULTS.md. Strong confound caveats.

## Reproduce / readability audit (2026-10-09)
Data: sources and SHA256 are in data_manifest/. Scripts read fixed paths under /tmp (download the files there first, check the SHA256, then run python3 src/run.py and python3 src/audit.py). Not independently re-run from a clean machine as part of this readability check; the numbers in RESULTS.md come from the original runs on 2 CPU / 2 GB. KNOWN GAP: src/run.py loads /tmp/poore/X.npy, idx.csv and cols.csv, which were made by a preprocessing step that is not in this repo, so run.py cannot be reproduced from the README alone. Raw voom.csv and meta.csv are the documented inputs; src/audit.py reads voom.csv directly. Treat run.py results as unverifiable by a third party until that step is added.
